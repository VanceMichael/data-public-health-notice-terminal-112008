# 冬季服务点公告的分语言终端换页

这里是可离线启动的合成上游，所有编号、时间和凭据都用于联调。

## 本地运行

使用 Node.js 22.23.4。`npm ci` 安装锁定依赖，再用 `npx playwright install chromium` 准备 Chromium。使用 Linux 时需有 Chromium 系统库。

```sh
npm start
npm test
```

不同终端分别启动服务和执行独立来源测试。默认地址为 `http://127.0.0.1:4173`，可通过 `SOURCE_PORT` 设置端口，也接受通用的 `PORT`，同时设置时以 `SOURCE_PORT` 为准。`GET /health` 用于确认来源服务已就绪。来源使用进程内演练时钟，启动时处于 `primary`。用 `PUT /_source_clock?step=stale` 推进到下一阶段，`GET /_source_calls` 查看本实例收到的业务请求。可查阶段为 `primary`、`stale`、`urgent`、`reconnect`、`display`。重启服务会重置时钟和请求记录。预置的源端回执按演练阶段出现，和本地应用是否已处理某次回执是两回事。
`npm test` 核对可访问的上游响应和合成资料，或用浏览器查看入口。

## 来源约定

市级公开页从 `/bulletins` 进入，地方语言页从 `/translation` 进入，屏控站点从 `/screens` 进入。段落卡片上原文号、适用点位、发布时间和生效时间均是业务内容。日期按东八区处理。地方语言页在同一段落同时列出原文段落识别码和所译版号，标明审译状态。
待办入口显示门户当前接收的换页单与设备实际显示的版本。设备组信息中，单页设备支持先将失效的页面切换为应急联系告示，整组设备可以同时启用组内页面。合成值班文件是 `fixtures/desk.json`。

## 换页代办

`agent/` 是浏览器代办：从市级信息页取公告、从语言页取译文，再通过屏控门户的可见界面
完成预览与登记。所有数据都是 `fixtures/` 里的合成演练资料。

```sh
npm start                                            # 另开一个终端
node agent/cli.mjs run --step primary                # 首次换页
node agent/cli.mjs run --step reconnect              # 离线设备回来、停办生效
node agent/cli.mjs run --step urgent --dry-run       # 只看页面与预览，不登记
node agent/cli.mjs report                            # 重看最近一次状态
```

`--state` 保存已审译文快照与操作流水（默认 `var/state.json`），`--out` 保存预览截图、
门户前后快照和 `status.json`。`agent/config.json` 里的 `portal.approvalCode` 是演练门户
的主管确认码，`terminals` 指定每台设备的语言。

处理规则：

- **只复用原文未变且适用范围未变的已审译文**。语言页只列出本轮改动段落时，未列出的
  段落从快照沿用；版号、原文文字、适用范围三者任一不同即重新组页。待审/未审译文
  不进快照，也不会出现在已发布页面上。
- **译文待补**时用 `fixtures/desk.json` 的 `fallback` 应急文字，没有配置则用官方原文暂代。
- **停办生效**后，该点位的地点与时段段落撤下，通用联系段与应急联系保留；其他点位
  与常规段落不受影响。复行通知恢复显示。
- **先清理再登记**：版本已过时的挂起换页先从待办撤下，单页设备一次最多一页在途。
  登记前必须先在预览页确认公告、语言与设备，并留截图。
- **中途生效**：预览之后重新抓取上游；等待中的画面若已过时则作废并重新预览，作废的
  预览同样留截图，避免把两个版本的公告拼在一起。
- **只有屏幕登记显示已确认/已显示**才算完成；离线或仍显示旧版的设备记为“需要人工上屏”。

演练时钟默认取“上游已发布的最新生效时刻”：上游既然已经给出 `urgent` 阶段的 12:10
停办段，本轮就按它已生效处理。需要固定时刻或改回系统时钟时，在配置里写
`clock: { now: "<ISO 时间>" }` 或 `clock: { mode: "real" }`。

`status.json` 按服务点汇总门户已接收、设备已显示、替代文案仍在使用、需要人工上屏四种
情况，并记录已登记内容的公告出处（公告号、发布时刻、抓取时刻）与所用译文版号。
